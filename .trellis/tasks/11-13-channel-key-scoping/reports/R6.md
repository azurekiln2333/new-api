## R7 多密钥渠道「显示当前密钥」两把 key 混作一串
- 结论：**只是显示错了，库里是对的**。`AddChannel` 按行拆分并用 `\n` 拼接、`MultiKeySize` 取拆分后数量（既有用例 `TestAddChannelReturnsCreatedIDs` 已锁定）；`GET /api/channel/:id/key` 返回的就是 `key1\nkey2`。错在展示：抽屉用单行 `Input` 渲染，换行被吞掉。
- `web/.../hooks/use-channel-key-disclosure.ts`：新增派生值 `channelKeyLines`（按 `\n` 拆分、去空行），`channelKey` 原样保留供复制。
- `web/.../channel-mutate-drawer.tsx`：多 key 渠道用只读 `Textarea` 逐行显示（复用既有组件，行数 2–8），单 key 渠道仍用原 `Input`；顺序即 key 下标顺序，与多 key 管理列表一致。
- 保存安全：揭示值不是表单字段，`use-channel-mutate-form` 在 `key` 为空时删掉 `payload.key`，后端 `Update()` 从库里读 key 列表并按 key 内容重映射 → 不改 key 直接保存不会改动 key、状态、模型范围与绑定用户。文案无新增。
- 结果：`channel-key-disclosure.test.tsx` 新增用例断言两把 key 各占一行且互不拼接；`bun run test`（两个测试文件）8 passed；`bun run i18n:sync` done；`bun run lint` 我这几个文件无告警（仓库其它文件仍有既有 error，未触碰）。
