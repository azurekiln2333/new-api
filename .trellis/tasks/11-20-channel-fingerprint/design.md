# Design

Local reviewed lm-detector SDK/assets with notices/checksums; bounded admin channel probes through existing eligibility, endpoint/capacity/timeouts. Keys server-side, no hosted dependency; progress/cancel/cost and reference-relative results without IQ/identity claims.

Use parent design.md section “Official status and local fingerprint detection” for full architecture, contracts, compatibility and rollback. Source evidence: ../11-19-playground-capabilities/research/status-fingerprint.md.

Dependencies: R4 protocols R6/R8 capacity R21 page; pinned SDK/assets/license. Ownership: pK / p9 review; root serializes shared files and locales. Use existing business components/services. Real database checks apply to all changed persistence/query behavior; independent modules build with GOWORK=off. Roll back owned requirement commits in reverse dependency order without overwriting parallel work or deleting user data.
