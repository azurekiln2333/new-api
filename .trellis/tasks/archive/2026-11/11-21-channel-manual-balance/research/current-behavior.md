# Existing channel balance, quota, and UI contracts

- `model/channel.go:50` defines `Balance` as the last upstream USD balance. `model/channel.go:54` defines `UsedQuota` as accumulated site billing. `model/channel.go:1676` updates usage through the batching path when configured, so the column cannot arbitrate admission and cannot initialize the new budget period.
- `controller/channel_authz.go:88–120` and `controller/channel.go:1237` exclude client edits to balance, usage, and snapshot fields from general channel updates. `controller/channel_balance.go` and `model/channel_balance.go` own upstream balance writes. Existing upstream balance checks can alter availability based on provider results. Keep those fields and paths responsible for their existing state.
- `router/channel-router.go:60–69` uses `ChannelRead` for ordinary read endpoints. Upstream balance queries and multi-key operations use `ChannelOperate` at lines 72–74 and 114. Use these permission contracts for channel budget reads and mutations respectively.
- `web/src/features/channels/components/channels-columns.tsx:417–420` hides the upstream balance display when the channel type cannot query it. Ordinary built-in multi-key channels lack provider balance querying, and plugin multi-key channels can report per-key snapshots. The new local budget action and display need their own visibility conditions.
- `web/src/features/channels/components/dialogs/balance-query-dialog.tsx` is specialized for upstream balance data, originates upstream updates and handles raw and Codex-specific responses. Reuse shared `Dialog` for the new form and `ConfirmDialog` for reset. `QuotaDetailsPopover` already presents label/value summaries. The existing user quota dialog provides an interaction reference but owns user-specific mutations. A channel feature component can compose the existing controls with channel data and mutations.
- `web/src/lib/format.ts` includes `parseQuotaFromDollars`, `quotaUnitsToDollars` and `quotaUnitsToEditableAmount`. `web/src/lib/currency.ts` handles station display currency. `toIntlLocale` normalizes UI language before locale-aware formatting. Upstream summaries already use their own provider currency formatters.
- `controller/model.go:266–285` and `controller/user.go:676–688` already include bound models in API and console lists. The shared design extends candidate selection and model visibility to incorporate positive remaining budget.
- `controller/channel_billing_test.go:216` has `TestChannelBalanceManagementDatabaseMatrix`. `controller/channel_multi_key_test.go:38` accepts `TEST_CHANNEL_SQL_DSN`. `.github/workflows/ci.yml:81–98` specifies real MySQL 8.4 and PostgreSQL 16 fixtures. The CI runs controller cases per DSN at lines 160–167.
- Existing UI regression candidates are `channel-balance-cell.test.tsx` and `row-actions-query-balance.test.tsx` under `web/src/features/channels/components/__tests__/` and `update-all-balances.test.ts` under `web/src/features/channels/lib/__tests__/`.
